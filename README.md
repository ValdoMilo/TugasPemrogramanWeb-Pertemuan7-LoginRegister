# Login & Register System - Tugas Pemrograman Web (Pertemuan 7)

Repository ini berisi *source code* untuk tugas mata kuliah Pemrograman Web pada pertemuan ketujuh. Proyek ini berfokus pada pembuatan **Halaman Autentikasi (Login & Register)** yang interaktif, elegan, dan responsif dengan penanganan validasi formulir di sisi klien (*client-side validation*).

## 📝 Deskripsi Proyek

Proyek ini merancang antarmuka pengguna untuk sistem masuk (login) dan pendaftaran akun baru (register). Fokus utama dari tugas ini adalah membangun aliran pengalaman pengguna (*user experience*) yang mulus saat berpindah antara formulir login dan register, serta memastikan bahwa data yang diinput oleh pengguna divalidasi dengan benar sebelum diproses.

Proyek ini melatih keterampilan dalam pembuatan tata letak formulir modern, interaktivitas JavaScript untuk beralih tampilan (*form toggling*), manipulasi elemen DOM untuk menampilkan pesan kesalahan (*error handling*), serta penanganan masukan pengguna (*input validation*).

## ✨ Fitur Utama

* **Satu Halaman / Seamless Form Toggle:** Kemampuan untuk beralih antara formulir Login dan Register secara dinamis tanpa perlu memuat ulang (*reload*) halaman.
* **Validasi Input Real-Time:** Memeriksa kelengkapan isi formulir, format email yang valid, serta panjang dan kesesuaian kata sandi (*password match*).
* **Fitur Tampilkan / Sembunyikan Kata Sandi (*Toggle Password Visibility*):** Mengizinkan pengguna untuk melihat atau menyembunyikan karakter kata sandi yang diketik.
* **Umpan Balik Visual & Pesan Error:** Menampilkan notifikasi atau penanda warna jika terdapat kesalahan pada pengisian formulir.
* **Desain Modern & Responsif:** Tampilan antarmuka yang bersih, simetris, dan fleksibel saat diakses melalui perangkat desktop maupun *smartphone*.

## 🛠️ Teknologi yang Digunakan

* **HTML5:** Struktur utama formulir dan elemen-elemen input.
* **CSS3 / SCSS:** *Styling* antarmuka, animasi transisi antar formulir, serta tata letak responsif.
* **JavaScript (ES6+):** Logika validasi *form*, manipulasi DOM, *event handling*, dan peralihan mode antarmuka.

## 🚀 Cara Menjalankan Proyek

1. *Clone* repositori ini ke komputer Anda:
   ```bash
   git clone https://github.com/ValdoMilo/TugasPemrogramanWeb-Pertemuan7-LoginRegister.git
   ```

2. Buka folder proyek menggunakan editor kode pilihan Anda (seperti **Visual Studio Code**).

3. Jalankan proyek dengan cara:
   * Menggunakan ekstensi **Live Server** di VS Code, atau
   * Membuka langsung file `index.html` di browser favorit Anda.

4. Uji coba dengan berpindah formulir antara Login dan Register serta mencoba fitur validasi input yang tersedia!
